# Skill Change Requests

Proposed additions to the portable agentic skills, derived from lessons learned during data product builds. One file per skill; each `##` section is one independent change request that can be submitted separately.

| File | Skill | CRs | Source |
|------|-------|-----|--------|
| `teradata-source-image.md` | teradata-source-image | 2 | source-image redeployment — FastLoad lock & column count mismatch |
| `data-product-design.md` | data-product-design | 1 | wide-table build — profiling timeout on wide tables |

## How to apply

Each CR document specifies:
- **Where to insert** the new section (relative to existing headings)
- **Why** (the incident that motivated it)
- **The exact markdown text** to paste

Apply by editing the skill's `SKILL.md` directly and submitting a PR to the skill's repository.
